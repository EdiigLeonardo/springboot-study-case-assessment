# Exercício 2 — PriceWatch

**Tempo: 40 minutos.**

Extensão com 80 mil utilizadores, submetida com uma atualização. O autor afirma que a extensão "só lê o preço em três lojas".

Perguntas a responder:
1. A afirmação do autor é verdadeira? Justifica com referências a linhas concretas.
2. Que dados saem da máquina do utilizador, e para onde?
3. Existe algum mecanismo que permita alterar o comportamento da extensão **depois** de aprovada na store? Descreve a cadeia completa.
4. Que sinais neste código te fariam escalar para uma análise mais profunda em vez de simplesmente pedir correções?
5. Classifica: aprovar / aprovar com alterações / rejeitar / escalar. Justifica em 3 linhas.

Dica de método: começa pelo `manifest.json` e pergunta-te sempre **"que privilégio tem"** antes de **"que faz"**.
