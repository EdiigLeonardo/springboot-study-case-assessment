# Exercício 1 — Markdown Clipper

**Tempo: 20 minutos. Cronometra.**

Chegou-te esta extensão para review antes de ser aprovada na store. É pequena e o autor diz que "só copia seleções para Markdown".

Entrega, em texto:
1. Lista de achados com severidade (alta / média / baixa).
2. Para os 3 mais graves: pré-condições, impacto e como o exploraria alguém.
3. Uma recomendação por achado.
4. Uma frase: aprovas, aprovas com alterações, ou rejeitas?

Não corras nada nos primeiros 15 minutos. Lê. O objetivo é treinar leitura, não uso de ferramentas.

Ficheiros: `manifest.json`, `popup.html`, `popup.js`, `clipper.js`, `sw.js`, `overlay.html`.
