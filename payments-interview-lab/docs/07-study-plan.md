# Intensive Study Plan

Do not try to memorize answers. Use the repository to build evidence behind each answer.

## Session 1 — Java + SOLID
Fix equality/deduplication, refactor risk rules, explain lambdas/streams, classify mutable vs immutable objects.

## Session 2 — Spring fundamentals
Trace dependency injection, bean scopes and proxies. Reproduce self-invocation and transaction behavior.

## Session 3 — Transactions + concurrency
Implement concurrency tests, fix idempotency and balance updates, compare locking strategies.

## Session 4 — Threads + performance
Replace unmanaged thread pool, remove blocking nesting, reason about pool size, measure bottlenecks.

## Session 5 — Angular/RxJS
Remove subscription leaks, implement refresh composition, fix form flow and Observable usage.

## Session 6 — Reusable card field + Material/CSS
Build a reusable card control, responsive layout and proper validation architecture.

## Session 7 — Batch + production support
Make settlement chunked/idempotent/resumable; improve logs, error taxonomy and metrics design.

## Session 8 — Mock interview
Use `06-interview-questions.md`. For each answer, point to a concrete before/after commit in your fixes.
