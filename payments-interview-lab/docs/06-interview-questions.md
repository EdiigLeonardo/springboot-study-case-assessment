# Phase 6 — Interview Simulation

Answer out loud, then prove it with code in this repository.

## Java

- What is SOLID? Give practical examples rather than definitions only.
- Frameworks use SOLID heavily. Where do you identify that in Spring/Angular?
- What is Singleton? What are its risks?
- Which Java features/versions have you used? What did each feature improve?
- What are anonymous functions/lambdas? Filter users who are exactly 30 years old.
- What is immutability? Where would you use it?
- How do you remove duplicate user names?
- How do you handle logs and exceptions?
- What is a thread? What concurrency problems have you encountered?
- How can you prevent concurrent execution inside a method? What does `synchronized` really guarantee?
- How do you scale processing? When would a thread pool help or hurt?

## Spring

- Have you worked with Spring? Which annotations do you use most and why?
- What is a Bean?
- What is Dependency Injection?
- What does `@Transactional` do? What are common traps?
- What is synchronous vs asynchronous execution?
- How does `@Async` work and what are proxy limitations?

## Angular

- Observable vs Promise?
- Which Angular building blocks have you used?
- Experience with styles and responsive layout?
- What is Angular Material and when would you use it?
- You have a credit-card field with formatting/mask + validation reused in several screens. How do you design it without copy/paste?

## Senior-style follow-ups

For every answer expect: “Why?”, “What breaks?”, “How would you test it?”, “What happens with 3 application instances?”, “What happens at 10x traffic?”, “What would you log/measure?”, and “What trade-off did you choose?”
