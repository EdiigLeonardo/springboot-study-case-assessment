# Exercício 07 — Testes que encontram bugs

Pegue os módulos 04-06 e construa uma estratégia de testes.

## Entregáveis
- unit tests para regras puras;
- MVC slice tests;
- repository tests;
- integração real com Testcontainers;
- contract tests para uma integração externa;
- teste de concorrência;
- teste de idempotência;
- pelo menos 5 bugs intencionalmente injetados e detectados por teste.

## Regra
Coverage alto não é objetivo. Cada teste deve declarar qual risco protege.
