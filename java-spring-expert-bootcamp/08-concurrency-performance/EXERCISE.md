# Exercício 08 — Concorrência, cache e performance

Implemente reserva de stock sob alta concorrência.

## Requisitos
- prove uma race condition com teste repetível;
- corrija de duas formas e compare;
- implemente cache com TTL;
- trate cache stampede;
- execute load test (script fornecido);
- capture p50/p95/p99;
- crie um cenário CPU-bound e um IO-bound;
- compare platform threads e virtual threads no caso adequado.

## Meta
Não otimizar até conseguir mostrar evidência do gargalo.
