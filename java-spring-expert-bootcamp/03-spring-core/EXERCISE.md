# Exercício 03 — Spring por baixo das anotações

Crie um pequeno sistema de notificações e aprenda o container.

## Tarefas
- Três implementações de `NotificationChannel`.
- Selecione por `@Qualifier` e depois por configuração.
- Crie um `BeanPostProcessor` que mede tempo de inicialização.
- Demonstre lifecycle de beans.
- Crie AOP para auditoria e explique por que proxies importam.
- Reproduza uma falha de self-invocation em método proxied.
- Inspecione o Condition Evaluation Report do Boot.

## Proibido
Usar anotações sem conseguir explicar quem as processa e em que fase.
