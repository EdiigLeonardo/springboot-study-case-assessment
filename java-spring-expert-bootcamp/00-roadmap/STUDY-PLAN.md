# Plano compacto

## Ritmo recomendado
Faça 2 blocos por semana. Cada bloco deve produzir código, testes e uma pequena defesa oral.

## Ordem obrigatória
01 -> 02 -> 03 -> 04 -> 05 -> 06 -> 07 -> 08 -> 09 -> 10.

## Método 30/50/20
- 30% leitura do enunciado e desenho.
- 50% implementação/testes.
- 20% explicar sem olhar para o código.

## Sinal de domínio
Você não memoriza anotações. Você prevê comportamento e sabe investigar quando a abstração quebra.
